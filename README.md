# OWASP Top 10:2025 Web Application Pentest Lab

A hands-on penetration test of OWASP Juice Shop, mapped to the OWASP Top 10:2025 categories.

## Purpose
Show practical web application security testing skills: finding vulnerabilities, proving them, and reporting them professionally.

## Lab environment
- Host: Windows, VirtualBox
- Attacker machine: Kali Linux (VM, NAT network)
- Target: OWASP Juice Shop (Docker, bound to 127.0.0.1 only)
- Tools: Burp Suite Community, OWASP ZAP, Firefox

## Legal and ethical note
All testing was done only against my own local, intentionally vulnerable lab. Testing systems you do not own is illegal under the UK Computer Misuse Act 1990.
